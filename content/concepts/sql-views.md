# SQL Views

A View is a virtual table that does not store data itself. Instead, it stores a query that is executed whenever the view is queried.

## Benefits of Views

-   **Security**: Restrict access to specific columns or rows.
-   **Simplicity**: Encapsulate complex joins and logic.
-   **Consistency**: Provide a stable interface even if underlying table structures change.
