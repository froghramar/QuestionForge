# Angular ARIA
Stabilized in Angular 22, the `@angular/aria` package provides a set of directives and tools to implement WAI-ARIA patterns correctly and easily.

Key Features:
- **Accessible State Management:** Directives that automatically sync internal component state (like `expanded` or `selected`) with the appropriate ARIA attributes.
- **Focus Management:** Tools for managing tab order and focus traps within complex UI widgets like modals or dropdowns.
- **Live Regions:** Simplified API for managing `aria-live` updates for screen readers.
- **Standardized Patterns:** Pre-built implementations for common widgets (Accordions, Tabs, Menus) that follow accessibility best practices out of the box.
