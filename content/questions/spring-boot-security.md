## Why This Is Asked
Security configuration requires an explicit request policy and distinguishes authentication from authorization.
## Key Concepts
- A `SecurityFilterChain` defines HTTP security behavior.
- Authentication establishes identity; authorization evaluates permissions.
- CSRF, sessions, CORS, and bearer tokens have distinct threat models.
- Method security complements route-level rules for sensitive operations.
