## Why This Is Asked

Views are a basic abstraction layer in databases. Interviewers want to know if you understand how to simplify complex schemas and provide security layers.

## Key Concepts

- **Abstraction**: Hiding complexity.
- **Security**: Column-level permissions.
- **Performance**: Standard vs Indexed Views.
